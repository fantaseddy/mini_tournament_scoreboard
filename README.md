# Mini Tournament Scoreboard

Mini Tournament Scoreboard is a RESTful API designed to manage and display the standings of teams participating in a mini tournament. It makes it so that the client is able to register a new non-existing team, view all the records of all the teams, retrieve or search for a specific team via their ID, modify existing records such as wins-losses data, and remove existing teams. These records are stored within Python list of dictionaries, so that user authentication and database won’t be necessary for its execution.
